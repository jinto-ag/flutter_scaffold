# Funding Support

flutter_scaffold is an open-source project that relies on community support to continue development and maintenance. If you find this project useful, please consider supporting its development.

## 🎯 Why Support flutter_scaffold?

Your support helps us:

- **Maintain the CLI tool** - Fix bugs, add features, and improve stability
- **Develop new templates** - More architecture patterns and integrations
- **Improve documentation** - Better guides, tutorials, and examples
- **Community support** - Respond to issues and help users
- **Infrastructure costs** - CI/CD, hosting, and distribution
- **Security updates** - Keep the tool secure and reliable
