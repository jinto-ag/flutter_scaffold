# 🚀 flutter_scaffold v0.1.0-beta - Public Preview Release

This is the first public beta release of **flutter_scaffold**, a production-grade Flutter project scaffolding tool with Clean Architecture support.

## ⚡ Quick Start

### Installation
```bash
# Install globally
dart pub global activate flutter_scaffold

# Or clone and install from source
git clone https://github.com/jinto-ag/flutter_scaffold.git
cd flutter_scaffold
dart pub global activate --source path .
```

### Create Your First Project
```bash
# Interactive setup (recommended)
flutter_scaffold interactive

# Or direct creation
flutter_scaffold create my_app
cd my_app
flutter pub get
```

## 🎯 What's Included

- 🏗️ **Clean Architecture** - Proper layered structure out of the box
- 📦 **Feature Modules** - Add features with complete architecture
- 🔧 **Template Engine** - Powerful templating with conditionals and logic
- 🛠️ **Auto Dependencies** - Riverpod, GoRouter, Freezed automatically
- ✅ **Code Generation** - Build runner integration
- 🎨 **VS Code Extension** - Template development tools
- 🧪 **Testing Framework** - Comprehensive E2E testing
- ⚙️ **Configuration** - YAML-based project configuration
- 🚀 **Interactive Mode** - Guided project setup
