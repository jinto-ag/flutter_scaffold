## How to Become a Contributor

### First-Time Contributors

We welcome contributions of all types! Here's how to get started:

1. **Find an Issue**: Look for issues labeled "good first issue"
2. **Fork the Repository**: Create your own copy
3. **Make Changes**: Follow the [Contributing Guide](CONTRIBUTING.md)
4. **Submit PR**: Open a pull request with your changes

### Regular Contributors

Consistent contributors may be invited to:

- Join the core team as a maintainer
- Get commit access to the repository
- Participate in roadmap planning
- Help with release management

### Types of Contributions

We recognize contributions in various forms:

#### Code Contributions
- Bug fixes and new features
